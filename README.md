# Worst AI Advice

One line of the worst possible advice an AI assistant could give, delivered
deadpan in the confident, tidy voice of a helpful chatbot: microwave your
phone to charge it faster. A small Python program (`main.py`) writes the line
to `/output/entry.txt` (or `$OUTPUT_PATH` when set). Deterministic, stdlib
only, no network.

Entry for the make.fun bounty "Worst AI Advice: The 48-Hour Tight Line Open".
